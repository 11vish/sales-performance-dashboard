Sales Performance Dashboard

1. Project Overview

An interactive sales performance dashboard created using Microsoft Power BI. It summarizes sales, profit, and order activity and allows users to explore performance across regions, product categories, and time.

2. Objectives

Monitor key sales performance indicators.
Compare sales across product categories and regions.
Examine monthly sales trends.
Enable interactive regional analysis.

3. Tools Used

Microsoft Power BI Desktop
Microsoft Excel (source workbook)

4. Dashboard Contents

Total Sales KPI
Total Profit KPI
Total Orders KPI
Sales by Product Category chart
Monthly Sales Trend line chart
Sales by Region chart
Region slicer

5. How to Use

-Open the Power BI report file (.pbix) in Power BI Desktop.
-View the KPI cards for the overall totals.
-Use the Region slicer to select a region.
-Observe how the KPI cards and charts respond to the selection.
-Clear the slicer selection to return to the overall view.

6. Data Notes

The report uses an Excel workbook containing Orders, People, and Returns data. A distinct Order ID lookup table was created to support order counting and relationships.

7. Project Status

The report visuals, dark theme, and interactive Region slicer have been created and tested.
